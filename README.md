# 谁是卧底

AstrBot QQ 官方群聊“谁是卧底”游戏插件，全部操作依靠按钮完成。

## 词库

插件使用 `cs/谁是卧底词库.csv` 中的词语对，共 600 多组。文件格式：

```text
分类,词语A,词语B
水果,苹果,梨
```

如果词库文件不存在，会自动回退到内置的少量词语对。

## 游戏规则

- 玩家人数 4-12 人。
- 每局随机选出一组相近词语。
- 大多数玩家是平民，拿到同一个词语。
- 少数玩家是卧底，拿到另一个相近词语。
- 可选白板玩家，拿到“白板”。
- 玩家点击自己的“看词”按钮查看词语。
- 按顺序轮流发言：
  - 当前发言人会看到“发言结束”按钮；
  - 其他玩家看到自己的看词按钮和“开始投票”按钮。
- 每轮讨论后发起投票，所有存活玩家投票淘汰一人。
- 平票则无人出局。
- 全部卧底/白板出局，平民阵营获胜。
- 卧底/白板人数不少于平民时，卧底阵营获胜。

## 命令

| 命令 | 说明 |
| --- | --- |
| `卧底菜单` / `卧底帮助` | 查看帮助 |
| `卧底创建` | 创建房间 |
| `卧底加入` | 加入房间 |
| `卧底退出` | 开局前退出 |
| `卧底开始` | 房主或管理员开始游戏 |
| `卧底看` / `卧底状态` | 查看公开状态和编号 |
| `我的词语` | 显示自己的看词按钮 |
| `发言结束` | 当前发言人结束发言，轮到下一位 |
| `开始投票` | 进入投票阶段 |
| `投票 1` | 投票给 1 号玩家 |
| `统计投票` | 手动统计当前票数 |
| `卧底结束` | 房主或管理员结束房间 |

## 按钮设计

- 每个存活玩家有自己独立的“看词”按钮，只有本人可见；有几个人就有几个按钮。
- 发言阶段当前发言人会看到“发言结束”按钮。
- 发言阶段所有人看到“开始投票”按钮。
- 投票阶段每名未投票玩家看到自己的“投票”按钮，点击后输入编号。
- 投票全部完成后自动结算。
- 所有按钮均不带占位符。
